# Welcome

Mora 타이밍이 실제로 어떤지 **눈으로 보는 자리**. 노래를 틀면서 가사를 글자마다 칠합니다.

```
                          새파란 눈물을 흘려보내요
                            ▔▔▔▔▔▔ ▔▔▔▔
                          ↑ 다 부른 글자        ↑ 아직 안 부른 글자
                                   ↑ 지금 부르는 글자 — 여기서 진해진다
```

낱말마다 시각이 있으므로 **낱말 안에서도** 칠할 수 있습니다. 「흘려보내요」가 2.6초 동안 불리면 그 2.6초에 걸쳐 다섯 글자가 차례로 물듭니다 — 줄만 칠하는 자막과 다른 점이 그것입니다.

## 쓰기

```bash
pip install git+https://github.com/aodjo/mora-python yt-dlp yt-dlp-ejs

python play.py --title "영원은 그렇듯" --artist "리도어(Redoor)" --browser chrome
```

**곡 이름만 주면 됩니다.** 가사도 음원도 알아서 구해 옵니다:

| | 어디서 | |
|---|---|---|
| 가사 | bugs · flo · genie · melon · vibe | 받은 첫 곳 |
| 음원 | 유튜브 | **길이가 맞는** 영상 |

유튜브가 로그인 없는 요청에 「사람인지 확인하라」고 하므로 `--browser` 로 브라우저에 있는 로그인을 빌립니다(chrome · safari · firefox · edge · brave). 쿠키는 `yt-dlp` 가 바로 읽어 쓰고 어디에도 남기지 않습니다. `MORA_BROWSER` 로 미리 정해 둘 수도 있습니다.

받아 온 음원은 `~/.mora-welcome` 에 두고 다음에 다시 씁니다(`--keep` 으로 바꿉니다).

**엉뚱한 영상을 받지 않게 제목과 길이를 둘 다 봅니다.** 제목이 안 맞으면 버리고, 제공처가 말하는 곡 길이와 4초 넘게 다르면 거릅니다. 길이만 보면 안 됩니다 — 237초짜리 「영원은 그렇듯」을 찾다가 238초짜리 「Forever Has Always Been」이 걸린 적이 있습니다 — 그 검사가 없던 시절 산토리 자리에 아크라포빅 영상이 붙어 딴 노래로 타이밍이 나왔습니다. 라이브·커버·한 시간 반복은 제목으로도 거릅니다.

가진 파일이 있으면 그걸 씁니다:

```bash
python play.py 노래.m4a 가사.txt --isrc KRA401200001
```

곡 길이는 음원에서 직접 읽으므로(`ffprobe`) 따로 안 적어도 됩니다.

가사는 **가진 그대로** 두면 됩니다. 줄바꿈이 다르거나 괄호 표기가 달라도 서버가 지문으로 견주어 제 자리에 얹습니다. 얼마나 맞았는지는 화면 위에 `word 1.00` 처럼 나옵니다.

## 소리와 시계

자리를 아는 길이 둘이고, 있는 쪽을 씁니다.

| | 어떻게 | 정확도 |
|---|---|---|
| `sounddevice` + `soundfile` 이 있으면 | 내보낸 **표본을 센다** | 밀리지 않습니다 |
| 없으면 | `ffplay` 를 띄우고 **시계로 센다** | 재생기가 뜨는 만큼 늦습니다 |

두 번째 길이면 화면 위에 「시계로 셈」이라고 나옵니다. 가사가 일정하게 늦거나 이르면 `--offset` 으로 맞추세요(기본 250ms, 클수록 가사가 빨라집니다).

표본을 세는 쪽이 이 데모의 본뜻에 맞습니다 — 타이밍을 보러 온 자리에서 시계가 밀리면 무엇을 보고 있는지 알 수 없으니까요.

```bash
pip install sounddevice soundfile
```

## 색

| | |
|---|---|
| 다 부른 글자 | 밝게 |
| 지금 부르는 글자 | 밝기로 **번져 간다** |
| 아직 안 부른 글자 | 흐리게 |

낱말 안의 글자 시각은 서버가 주지 않으므로 낱말 길이를 글자 수로 고르게 나눕니다. 노래가 실제로 그렇지는 않지만 눈에는 부드럽게 흐릅니다. 색은 `play.py` 맨 위의 `DIM` · `LIT` · `NOW` 로 바꿉니다.

## 알아 둘 것

- 터미널이 truecolor 를 알아야 합니다(`COLORTERM=truecolor`). 요즘 터미널은 대부분 됩니다.
- 이 곡의 타이밍이 Mora 에 **공개돼 있어야** 합니다. 없으면 「쓸 수 있는 타이밍이 없다」로 끝납니다.
- `Ctrl-C` 로 멈춥니다.
- 가사를 받아 오는 쪽은 저쪽 화면이 바뀌면 깨집니다. 한 곳이 막혀도 나머지로 갑니다.
- `yt-dlp-ejs` 와 노드가 있어야 합니다. 유튜브가 미디어 주소에 JS 로 푸는 서명을 걸어서, 그것을 풀 물건이 없으면 「페이지를 다시 불러와야 한다」로 막힙니다.
